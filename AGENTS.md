# Agent O.S.A. task workflow

Read `tasks/README.md`, `tasks/GATES.md`, and the current task before changing code.
Implement one task at a time, keep changes within its declared files, and use
fictitious data only. Do not enable file moves, external e-mail, or external
LLMs by default. Do not mark a gate accepted without the required evidence and
human review.

For delegated implementation, read `tasks/delegation/README.md`, the parent task,
and only the assigned subtask in `tasks/delegation/TASK-NNN.md`. Load the contract
sections it names; verify producer interfaces before changing consumers. Stop
after the assigned unit and return evidence. Critical review and native/live
prerequisites must be satisfied before releasing dependent work.
